Standards-composed workflow

OTIO → OpenAssetIO → PostProject

An ordinary OTIO media reference carries a durable PostProject entity URL. The upstream OpenAssetIO linker asks the PostProject Manager for locatable content, and PostProject resolves the representation against the production and this machine's roots.
