PostProject
Documentation Source

Open-source media sharing for film and video software

All your video software, working from the same page.

Today, a film passes through several programs: one for editing, one for effects, one for sound. Each keeps its own list of your clips, and every hand-off means exporting, re-importing and fixing “media offline” warnings. PostProject is a free building block that lets these programs share one database of your media instead. Each program keeps its own project files, but what one of them learns about a clip, the others know too.

01

One database, every program

Your editing, effects and sound programs can all open the same PostProject database at the same time. As soon as the editor imports a take, the effects program can see it; when the effects program renders a shot, the editor can pick it up. There is nothing to export, re-import or keep in sync by hand.

02

Works on any computer

A project remembers “camera footage” instead of a fixed location like “D:\Footage”, so it opens on your laptop and in the studio alike. A fingerprint of each file lets PostProject recognize moved clips. If two files match equally well, it lets you choose instead of guessing.

03

One clip, many versions

The original camera file, a smaller copy for smooth editing, and the finished color-graded result all count as one clip that every program recognizes. PostProject also records which program made each result and from what, so anyone can trace a finished shot back to its source.

For software developers

Hand an edit to another program and it still finds every clip.

A production is a single database file that several programs can use together. Every change is recorded, so each program can ask what the others have changed since it last looked. PostProject also works with open industry standards: an edit saved as OpenTimelineIO, a common format for exchanging timelines, can refer to clips by their PostProject ID, and the receiving program uses OpenAssetIO to ask PostProject where each clip is on this computer. Developers can use PostProject from C, C++, Python or the command line. Everything stays on your computers; nothing is uploaded.
